# SevenMentor Website Clone

A responsive website clone of the SevenMentor training and placement
institute website, developed using HTML, CSS and JavaScript.

## 📌 Project Overview

This project recreates the major sections of the SevenMentor website
with a responsive design for mobile, tablet and desktop screens.

## ✨ Features

- Responsive navigation
- SevenMentor logo and header
- Hero section
- Animated statistics counters
- Alumni companies section
- Infinite company-logo sliders
- Why SevenMentor section
- Free demo CTA section
- Technology/programming section
- Courses section
- Course categories
- Course search UI
- Course cards
- Industry affiliations
- NASSCOM certification section
- Professional certifications
- Responsive design
- Mobile, tablet and desktop layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- CSS Flexbox
- CSS Grid
- CSS Animations
- Responsive Web Design
